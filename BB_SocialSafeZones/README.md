# BB_SocialSafeZones

## Description

Overlays safe zone guides for social media delivery formats. Select a Delivery format, adjust overlay colour and opacity, toggle the border and UI cutouts, and use the Adjustments controls to reposition or scale the source image.

## Flame Requirements

2016.0.0

- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
