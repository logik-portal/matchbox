# CPGP_Flame

## Description

This Matchbox shader generates a simple moving flame.
You can change the color of the base and trail of it.
Since we can't have RGB in the GUI yet, X stands for R, Y for G, Z for B.
Demo: https://vimeo.com/80257415
Contact us at dev@cpgp.nu if you want us to customize or create new shaders for you!
