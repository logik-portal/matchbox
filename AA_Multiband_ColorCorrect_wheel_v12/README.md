# AA_Multiband_ColorCorrect_wheel_v12

## Description

Six-band colour corrector: Master plus fixed Low, Low Mid, Mid, High Mid and High luminance bands. Each tab includes Gamma, Gain, Offset, Exposure, Contrast, Saturation and a Colour Wheel. Wheel Hue sets the target hue; Gain sets strength; Mix scales the wheel effect. Use Picker limits a tab by colour; Picker Tol sets range and Picker Soft feathers the selection. Show Matte displays the active selection in white. Optional external Matte limits all corrections: white = full, black = protected, gray = partial. Bypass disables the current tab.
