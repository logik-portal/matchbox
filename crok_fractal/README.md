# crok_fractal

## Description

Creates a fractal pattern.

Setup:

    - Zoom : zoom in and out
    - Resolution : fractal detail
    - Offset : offset fractal pattern
    - Speed : speed of building the fractal
    - Zoom : zoom in and out
    - Gain : brightness of the fractal texture
