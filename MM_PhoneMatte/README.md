# MM_PhoneMatte

## Description

Resolution-independent rounded-rect phone matte with an adjustable lozenge-shaped camera cutout, for matting real phone camera plates back into a mockup.

## Flame Requirements

2015.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported

## Shader Type

Matchbox
