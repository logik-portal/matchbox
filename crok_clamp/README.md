# crok_clamp

## Description

Use this shader to get broadcast safe colors
Input:
- Front: source clip
Clamp:
- Chroma: max chrominance
- Luma: max luminance 
Demo clip: http://vimeo.com/117628260

## Flame Requirements

2015.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
