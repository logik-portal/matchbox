# Ls_Nail

## Description

Nail - warp an area of the Front and Matte to follow a track, for nailing down floaty CG.  Paste XY tracks from the FG and the BG on the From and To channels, and input a matte for the area to affect
Demo: http://youtube.com/watch?v=GOQAAb9NqAM
lewis@lewissaunders.com
