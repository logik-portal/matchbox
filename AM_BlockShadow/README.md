# AM_BlockShadow

## Description

Block style drop shadow. Extrudes the matte along an angle, or towards a vanishing point, to create a solid shadow, which can be set back from the fill, shaded along its length, softened and outlined. The fill (Front or a colour) is comped over it. The shadow can be coloured with a flat colour or the optional Shadow Fill input. Outputs premultiplied RGB and the combined matte. (andrew.miller@mtifilm.com).
