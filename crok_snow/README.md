# crok_snow

## Description

Creates snow.

Setup:

    - Layers: number of snow layers
    - Depth: depth of field
    - Wind : amplitude of the wind
    - Detail: add aditional noise
    - Speed: animation speed
    - Size: snowflake size

Updates:

    - Boosted speed to 100 max instead of 10. Abuse the effect things besides snow!
