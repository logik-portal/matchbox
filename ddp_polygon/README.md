# ddp_polygon

## Description

ddp_polygon - Polygon line animation.
You can generate a regular icosagon from a regular triangle and control the line animation of the perimeter.
The line width does not change even with XY scaling.
Fill is also an option.
(https://www.instagram.com/nbmk1985/)
