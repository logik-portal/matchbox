# crok_perlin

## Description

Creates a perlin noise like pattern.

Setup:

    - Frequency: Zoom in / out
    - Gain: brightness of the patter
    - Speed: animation speed
    - Offset: offsets the noise pattern
    - Colour: colour of the patters
