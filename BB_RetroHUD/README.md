# BB_RetroHUD

## Description

Retro sci-fi HUD overlay. Inspired by Alien, Aliens, Blade Runner, 2001 A Space Odyssey, and TRON. Two-pass: pass 1 draws 13 animated HUD elements on a black background, pass 2 applies a CRT/old-TV filter.

## Flame Requirements

2026.0.0
