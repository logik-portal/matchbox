# Ls_Posmatte

## Description

Posmatte - pull a spherical matte from an XYZ position pass.  Make sure to pick from the Position input with the picker set to 16fp!  The matte will even stick to animated meshes if you ask your CG peeps for a 'rest position' P pass, or a 'P at frame 1' pass
Demo: http://youtube.com/watch?v=11Q4RHJz230
lewis@lewissaunders.com
