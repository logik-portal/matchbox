# crok_fisheye

## Description

This Matchbox shader creates a fisheye effect.
Setup:
- Distortion: adjust the amount of barrel distortion applied
Demo clip: https://vimeo.com/128069220
Based on: https://www.shadertoy.com/view/4s2GRR by SanchYESS
