# BB_ShadowDensity

## Description

Shadow density and saturation control. Uses a smooth luminance mask to isolate the shadow zone (full effect at black, fading to zero at the pivot). Shadow Lift pulls down luminance; Shadow Desat reduces saturation toward neutral grey. Both effects share the same mask so lift and desat are always spatially consistent. Supports Rec.709, Scene-Linear, ACEScg, ACEScct, and ARRI LogC4.
