# crok_acid

## Description

This LightBox shader will create some funky ACID patterns
IMPORTANT: This is a volumetric shader. Please add a large sphere to the scene, to be able to see something.
Demo clip: http://vimeo.com/131350537
Based on http://glslsandbox.com/e#25386
Ligtbox version

## Flame Requirements

2016.0.0

- ❌ **Transition**: Not supported
