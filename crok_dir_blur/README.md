# crok_dir_blur

## Description

Creates a directional blur.

Version: 1.1a

Input:

    - Front: source clip

Output:

    - Result: result clip

Setup:

    - Horizontal: blur amount
    - Vertical: blur amount
    - Iterations: number of steps to create the blur
    - Gain: gain applied to image
