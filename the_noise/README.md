# the_noise

## Description

This shader creates diffferent noise patterns
Concrete noise based on https://www.shadertoy.com/view/4lfGRs 
Simplex3D noise based on https://www.shadertoy.com/view/XtBGDG 
FBM noise 
Fractal Noise based on https://www.shadertoy.com/view/Msf3Wr 
Value Noise based on https://www.shadertoy.com/view/lsf3WH 
Worley Noise  based on https://www.shadertoy.com/view/ldB3zc 
Ridged Noise based on https://www.shadertoy.com/view/ldj3Dw 
Perlin Noise based on https://www.shadertoy.com/view/MllGzs 
Perlin v2 Noise based on https://www.shadertoy.com/view/MlS3z1 byRenoM
Crawling Noise based on https://www.shadertoy.com/view/lslXRS 
Cells on Fire based on https://www.shadertoy.com/view/lsX3z4 
Water Noise based on https://www.shadertoy.com/view/llsGWl 
Fluid Malone Noise based on https://www.shadertoy.com/view/4s23WK 
Slabrie Noise based on https://www.shadertoy.com/view/ldBSDd 
Frederic Noise based on https://www.shadertoy.com/view/4tfXzl 
Flow Noise based on https://www.shadertoy.com/view/Md23Wc 
Francis Noise based on https://www.shadertoy.com/view/ldfGWj
