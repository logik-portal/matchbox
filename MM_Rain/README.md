# MM_Rain

## Description

Procedural rain with turbulence, swirl, clustering and depth layers. Output on black - Screen or Add, or composite directly over an optional Background Plate.

## Flame Requirements

2015.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported

## Shader Type

Matchbox
