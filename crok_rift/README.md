# crok_rift

## Description

Distorts side-by-side stereo images to be useable with the Oculus Rift.

Input:

    - Front: source clip

How to use:

    Just pipe in a side by side Stereo 3D clip and the shader will convert it to a Oculus Riftenabled clip.
