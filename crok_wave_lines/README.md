# crok_wave_lines

## Description

This Matchbox shader creates a wave line pattern.
Setup:
- Lines: number of waves
- Speed: speed of the waves
- Offset: offset lines in time
- Brightness : brightness of the lines
- Glow: overall glow 
- Colour: colour for the 4 gradient points  
Demo clip: http://vimeo.com/83878609
Based on http://glsl.heroku.com/e#13475.0
