# crok_cameraflash

## Description

Creates simple camera flashs.

Setup:

    - Flickering: amount of flickering
    - Density: amount of flashes
    - Size: size of the flashes
    - Seed: change seed value

## Flame Requirements

Not specified

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
