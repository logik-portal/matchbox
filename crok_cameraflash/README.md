# crok_cameraflash

## Description

This Matchbox shader creates simple camera flashs.
Setup:
- Flickering: amount of flickering
- Density: amount of flashes
- Size: size of the flashes
- Seed: change seed value
Demo clip: http://vimeo.com/121594578
Based on http://glsl.herokuapp.com/e#15514

## Flame Requirements

2012.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
