# AA_DirectionalBlur

## Description

Directional blur with angle and 0°/180° pairing. Proportional toggle for symmetric lengths; optional Matte to constrain. Center point biases strength away from a chosen focus.

## Flame Requirements

2025.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
