# AB_Halation

## Description

Film halation with Low and High quality modes. Low = fast 8-tap kernel for interactive work. High = smooth 48-tap kernel for finals.

## Flame Requirements

2017.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported

## Shader Type

Matchbox
