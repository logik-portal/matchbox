# crok_cmyk_halftone

## Description

Simulates CMYK Halftone patterns.

Input:

    - Front: source clip

Setup:

    - Minimum : minimum pattern
    - Maximum : maximum pattern
    - Gain : brightness of the pattern
    - Scale: scale pattern

Updates:

    - Modified default input to be Front.
