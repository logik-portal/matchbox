# crok_cmyk_halftone

## Description

This Matchbox shader simulates CMYK Halftone patterns.
Input:
- Front: source clip
Setup:
- Minimum : minimum pattern
- Maximum : maximum pattern
- Gain : brightness of the pattern
- Scale: scale pattern
Shader developer: tsone
Based on https://www.shadertoy.com/view/Mdf3Dn
