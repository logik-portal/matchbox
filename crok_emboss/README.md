# crok_emboss

## Description

This Matchbox shader simulates an emboss effect.
Input:
- Front: source clip
Setup:
- Height: bump height 
- Specular: adjust the glossiness
- Light Height: height of the lightsource
- Position: light position in x / y
Demo clip: http://vimeo.com/112310423
