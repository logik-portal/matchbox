# crok_voronoi

## Description

Creates voronoi noises.

Setup:

    - Octaves: Octaves for the noise
    - Type: variations of the noise pattern
    - Zoom : zoom in/out
    - Detail: add aditional noise

    - Speed: animation speed
    - Offset: offsets the noise pattern
