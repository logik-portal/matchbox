# y_vray

## Description

Do minor relighting or just re-assembling of the most used Vray render passes. (In one node)

Global Illumination
Direct Lighting
Reflection
Specular
Refraction
Self Illumination

Obviously these can be jacked for whatever passes.

Updates:

    - Fixed for Flame 2025
