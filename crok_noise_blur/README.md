# crok_noise_blur

## Description

This Matchbox shader creates a noise texture similar to the popular Genarts Texture (start with a white frame).
Inputs:
- Front : source clip
Setup:
- Zoom : zoom in and out of the texture
- Rotation: direction of the blur
- Offset: offsets the texture
Demo clip: https://vimeo.com/82190139
Shader developer: Inigo Quilez - http://www.iquilezles.org/
