# crok_circuits

## Description

Creates circuits style patterns.

Setup:

    - Width: width of the lines
    - Zoom: zomin in / out of the fractal
    - Speed: speed of the conductive strips animation
    - Offset: offset animation in time
    - Position: position of the fractal
