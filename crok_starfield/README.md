# crok_starfield

## Description

Lightbox shader which creates a Starfield
NOTE: This shader works only, if you have a large sphere surrounding your scene
Lightbox version

## Flame Requirements

2016.0.0

## Supported Modes

- ❌ **Action**: Not supported
- ❌ **Transition**: Not supported
- ❌ **Timeline**: Not supported
