# crok_checkerboard

## Description

Creates a checkerboard pattern.

Setup:

    - Zoom: zoom in / out
    - Rotation: rotates the checkerboard
    - Aspect: aspect of the pattern
    - Colour: colour for the 2 tiles
    - Antialiasing: applies an AA filter to the rotated checkboard
