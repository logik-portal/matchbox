# crok_fire

## Description

Creates a noise texture similar to the popular Genarts Texture (start with a white frame).

Setup:

    - Noise : noise detail
    - Offset : offset noise pattern
    - Speed : speed of fire
    - Zoom : zoom in and out of fire
    - Amplitude : amplitude of fire
