# BB_FutureHUD

## Description

Animated sci-fi HUD overlay. Inspired by the holographic interfaces of Minority Report, Iron Man, and Pacific Rim. Camera locked to screen. All elements independently enabled and colour-controlled.

## Flame Requirements

2026.0.0
