# crok_crosshatch

## Description

Simulates a simple pencil sketch.

Input:

    - Front: source clip

Setup:

    - Density : How close together hatch lines should be placed
    - Width : How wide hatch lines are drawn

Updates:

    - Modified default input to be Front.
