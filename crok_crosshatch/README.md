# crok_crosshatch

## Description

This Matchbox shader simulates a simple pencil sketch.
Input:
- Front: source clip
Setup:
- Density : How close together hatch lines should be placed 
- Width : How wide hatch lines are drawn
Shader developer: doomedbunnies
