# crok_scanlines

## Description

Matchbox shader simulates CRT phosphor / shadow mask arrangements.
Setup:
- RGB Bar
- MG Bar
- RGB Triad
Based on Phosphor21x / http://filthypants.blogspot.de/2011/05/more-emulator-pixel-shaders-crt-updated.html
Shader developer: Caligari

## Flame Requirements

2015.0.0
