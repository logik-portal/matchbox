# crok_expon_blur

## Description

The Exponential Blur blurs an image with an exponential falloff.
Input:
- Front: source clip
Setup:
- Amount: amount of blur applied
- Blend: mix between the original image and the blurred one
Output Options:
- Clamp output: clamps the result to 0.0 - 1.0
