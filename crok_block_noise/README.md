# crok_block_noise

## Description

Creates blocky textures.

Setup:

    - Detail: texture detail
    - Seed: seed value
    - Speed: how fast the bubbles are moving
    - Offset: offset the animation in time
    - Size: size of the blocks
    - Aspect: aspect in x / y
    - Colour: block colour
    - Gain: adjust colour gain
