# Ls_Fireflies

## Description

Attempts to remove the hot firefly pixel noise that appears in CG renders with bright lights hidden behind other objects
Quick demo: https://www.youtube.com/watch?v=GuvRoN5WfM4
lewis@lewissaunders.com

2017.0.0
