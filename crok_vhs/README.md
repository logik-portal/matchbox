# crok_vhs

## Description

This Matchbox shader simulates an old VHS player.Setup:- Resolution: input texture resolution- Stripes Amount: amount of horizontal white stripes- Tape Wave: amount of horizontal tape distorion- Tape Crease: amount of horizontal stripes offset- AC Beat: amount of AC interferrences- Color Tint Amount: amount of color tint- Color: tint color- Color Bleeding Amount: amount of color bleeding- Offset: amount of color offset- Speed: how fast the stripes moves- Offset: offset the effect in timeShader developer: FMS_CatBased on www.shadertoy.com/view/MdffD7This work is licensed under a Creative Commons Attribution-NonCommercial-ShareAlike 3.0 Unported License.
