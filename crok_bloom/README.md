# crok_bloom

## Description

Simulates blooming.

Input:

    - Front: source clip

Setup:

    - Offset: offsets the glow to gives a streak like effect
    - Size: glow size
    - Strenght: glow strength

Updates:

    - Modified defeult input to be Front.
