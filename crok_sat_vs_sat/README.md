# crok_sat_vs_sat

## Description

This Matchbox gives you Resolve style 'Sat vs Sat' curve controls.
Input:
- Front: front image
Setup:
- Sat Multiplier: multiplies the saturation of the curves to give you the possibility to go over 1.0 Saturation

## Flame Requirements

2016.0.0

## Supported Modes

- ✅ **Action**: Supported
- ❌ **Transition**: Not supported
- ✅ **Timeline**: Supported
