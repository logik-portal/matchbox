# crok_lowfi

## Description

This Matchbox shader simulates NES, EGA and Gameboy video out.
Setup:
- Brightness: adjust brightness of the image
- NES: apply NES look
- EGA: apply EGA colour palette 
- GAMEBOY: apply a gameboy type colour pallete
Demo clip: http://vimeo.com/95587150
Based on https://www.shadertoy.com/view/MdfXDH
