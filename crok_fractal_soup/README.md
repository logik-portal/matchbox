# crok_fractal_soup

## Description

Creates a mandelbrot pattern.

Setup:

    - Speed : speed of building the fractal
    - Offset : creates different fractal
    - Gain : changes the brightness of the fractal
    - Colour: fractal base colour
    - Detail: fractal resolution
